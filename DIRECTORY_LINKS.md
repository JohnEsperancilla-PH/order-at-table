# Web Route Links

Browser links for your app routes (using local dev URL).

- Base URL: http://localhost:3000
- Example placeholders used below:
1. restaurantSlug = demo-restaurant
2. tableNumber = 1
3. orderId = sample-order-id
4. status = pending
